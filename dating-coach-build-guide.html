Build Guide — From Locked Prompt to Live Funnel

7 days, ~14 hours of work, total launch cost under $100. Follow in order. Each day’s checkpoint must pass before moving to the next.

What you’ll have at the end: a live quiz funnel where any prospect can submit 6 answers and receive a personalized email in Marina’s voice within 60 seconds — fully automated, ready to scale.

Day 0 — Pre-flight (30 minutes)

PRE-FLIGHT

What you need before opening any tool

  1. Decide on the brand domain: datingwithmarina.com (or whichever Marina chooses). Buy it on Namecheap or Cloudflare.
  2. Set up a business email: hello@datingwithmarina.com. Google Workspace ($6/mo) is the easiest.
  3. Decide on the legal entity: LLC in Marina’s state. File via LegalZoom or ZenBusiness (~$200–400, can run in parallel with everything else).
  4. Have a credit card and a bank account ready for Stripe.
Checkpoint: domain registered, email working, LLC paperwork filed. You can move on while LLC processes.

Day 2 — Build the Tally form (1 hour)

DAY 2~60 min

Create the 2-minute quiz

  1. Open Tally → + Create new form → Start from blank.
  2. Set form name: The 2-Minute Dating Diagnosis.
  3. Add the 6 fields exactly as specified in dating-coach-quiz-spec.html:
    • Field 1: Multiple Choice — Age range (5 options)
    • Field 2: Multiple Choice — Gender (4 options)
    • Field 3: Multiple Choice — Goal (4 options)
    • Field 4: Long Text — Biggest blocker (30 char min)
    • Field 5: Long Text — What feels heaviest (20 char min)
    • Field 6: Email — Where to send the answers
  4. Set field keys for each (Settings on each field): age_range, gender, goal, blocker, frustration, email. Critical — Make.com uses these.
  5. Add the intro page copy and the confirmation page copy from the spec.
  6. Style: Settings → Appearance → cream background (#f5f1ea), navy text (#1a1a2e), teal accent (#16a085).
  7. Set the form URL slug: dating-diagnosis. The full URL becomes https://tally.so/r/dating-diagnosis.
  8. Don’t enable the webhook yet. We do that on Day 3 after Make.com is built.
  9. Publish the form. Test it yourself with fake answers. Confirm validation works.
Checkpoint: form is live, you can submit it, validation rejects empty/short blocker fields, confirmation page shows correctly.

Day 3 — Build the Make.com scenario (3 hours)

DAY 3~3 hours

The automation that ties Tally, Claude, and Kit together

This is the most technical day. Take it slow. Test each step before adding the next.

Step 3A — Create the scenario

  1. Make.com → Create a new scenario.
  2. Name it: Quiz to AI to Email.

Step 3B — Module 1: Tally trigger

  1. Add module → search Tally → Watch Form Responses.
  2. Connect your Tally account (OAuth flow).
  3. Select the form: The 2-Minute Dating Diagnosis.
  4. Run the module once to grab the webhook URL it generates — copy it.
  5. Paste that webhook URL into Tally → your form → Settings → Integrations → Webhooks.
  6. Submit a test response on Tally and confirm Make.com receives it.
Checkpoint: a test Tally submission appears in the Make.com run history with all 6 fields visible.

Step 3C — Module 2: Anthropic API call

  1. Add module → HTTP → Make a request. (Use HTTP, not the Anthropic-native module — gives you cache control.)
  2. Configure:
    • URL: https://api.anthropic.com/v1/messages
    • Method: POST
    • Headers: 
      x-api-key: YOUR_ANTHROPIC_API_KEY
anthropic-version: 2023-06-01
content-type: application/json
    • Body type: Raw / JSON
  3. Body content: paste the locked system prompt from dating-coach-stack.html into the system field, with the knowledge base content directly inside it. Body shape: 
    {
  "model": "claude-sonnet-4-6",
  "max_tokens": 2000,
  "system": [
    {
      "type": "text",
      "text": "[VOICE RULES + EDGE CASES from locked prompt]"
    },
    {
      "type": "text",
      "text": "[FULL KNOWLEDGE BASE - all 50 polished Q&As]",
      "cache_control": { "type": "ephemeral" }
    }
  ],
  "messages": [
    {
      "role": "user",
      "content": "User's quiz answers:\n- Age: {{1.age_range}}\n- Gender: {{1.gender}}\n- Goal: {{1.goal}}\n- Biggest blocker: {{1.blocker}}\n- What feels heaviest: {{1.frustration}}"
    }
  ]
}
  4. The cache_control on the knowledge base block is critical — it caches the 50 Q&As across calls and cuts the per-quiz cost from ~$0.30 down to ~$0.03.
  5. Run a test — with the test Tally submission still in the queue, click Run once. Verify Anthropic returns a response.
Checkpoint: the HTTP module returns a 200 with a JSON body containing 3 personalized answer blocks in Marina’s voice.

Step 3D — Module 3: Add Subscriber to Kit

  1. Add module → search Kit (ConvertKit) → Add Subscriber to a Form.
  2. Connect your Kit account (API key from Kit → Account Settings → Advanced).
  3. Form: create a new Kit form named Quiz Submitters.
  4. Email: map to {{1.email}} from Tally.
  5. Custom fields: map blocker, goal, age_range, gender, frustration to matching Kit custom fields. Also store the AI’s output as a custom field called ai_response — that’s how the email template will pull it in.

Step 3E — Module 4: Apply nurture tag

  1. Add module → Kit → Tag a Subscriber.
  2. Apply tag: quiz-day-0.
  3. This triggers the 5-email nurture sequence we set up on Day 4.

Step 3F — Activate

  1. Click the on-off switch at the bottom-left to activate the scenario.
  2. Schedule: every 1 minute (or instantly — Make.com defaults to instant for webhooks).
Checkpoint: submitting a real test on the Tally form triggers all 4 modules end-to-end, and you receive a personalized email in Marina’s voice within 60 seconds.

Day 4 — Set up Kit (2 hours)

DAY 4~2 hours

The email template + the 5-email nurture sequence

  1. Email template: Kit → Templates → New email. Subject: Your 3 personalized answers, {{ subscriber.first_name }} — from the quiz. Body: include the Liquid variable {{ subscriber.ai_response | strip_html: false }} in the body, surrounded by the standard Marina opening / closing.
  2. The trigger: Kit → Automations → New Visual Automation. Trigger: tag quiz-day-0 applied. First action: Send the email template above.
  3. 5-email nurture sequence (sent over 7 days after the quiz):
    • Day 1: “Did one of those 3 answers land?” (soft re-engagement)
    • Day 3: “The most expensive dating mistake I see” (one piece of teaching)
    • Day 5: “What changed for [pseudonym client]” (anonymized story)
    • Day 7: Soft pitch for the $497 Clarity Session (with Stripe link)
    • Day 14: Final “here’s what working with me looks like” with the Stan Store link
  4. Marina drafts the 5 emails. I can help draft them when she’s ready.
Checkpoint: the personalized email arrives correctly formatted, the nurture sequence is queued and visible in the visual automation.

Day 5 — Stan Store + Stripe (1 hour)

DAY 5~60 min

The link-in-bio destination

Checkpoint: a phone visiting the Stan Store URL sees a clean page, the quiz button works, the Stripe button completes a $0 test transaction.

Day 6 — End-to-end testing (1 hour)

DAY 6~60 min

Five real test runs

  1. Submit the Tally form 5 times with 5 different fake personas (use the ones from Persona #3-7). Use 5 different real email addresses you control (Gmail aliases work).
  2. For each: confirm the email arrives in <90 seconds, voice is Marina, 3 questions are reasonable, the personalization rule held (no canned KB openers).
  3. If any of the 5 fail: tune the system prompt in Make.com (one rule at a time), then re-test.
  4. Once all 5 pass: lock the system prompt — never edit again without re-running this test.
If a test reveals voice drift: the most common fix is tightening the personalization rule or adding a specific phrase to the NEVER list. Voice tuning playbook is in dating-coach-voice-tuning.html.

Day 7 — Soft launch (1 hour + ongoing)

DAY 7~60 min + monitoring

Get the first real users on the system

  1. Design Carousel #1 in Canva using dating-coach-carousel-1.html as the spec. Export 8 PNGs.
  2. Post on Instagram, TikTok, Facebook (same time, same caption).
  3. DM 20 people in Marina’s personal network: “Doing a soft launch — would love your honest take. Take this 2-minute quiz and tell me what you think.”
  4. For the first 50 real submissions, Marina reads each email before it would have gone out. (Set the Make.com scenario to manual approval for the first batch — or just monitor as they go.)
  5. Track 3 numbers in a simple spreadsheet:
    • Quiz views → quiz completions (target: > 50%)
    • Quiz completions → email opens (target: > 70%)
    • Email opens → replies (target: > 5%)
Checkpoint: 50 real submissions through the system. Voice intact. At least 1 reply asking a follow-up question. Marina has had at least one real conversation that came from the funnel.

Beyond Day 7 — Scale

SCALE

What unlocks once the funnel is proven
